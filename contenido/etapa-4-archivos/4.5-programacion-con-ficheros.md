# 4.5 Programación con ficheros

*Anterior: [4.4 Tipos de ficheros](4.4-tipos-de-ficheros.md) — Siguiente: [4.6 Flujo de datos](4.6-flujo-de-datos.md)*

Trabajar con un archivo se parece mucho a lo que ya haces con `cin` y `cout`. La diferencia es
que `cin` y `cout` ya están listos desde que empieza el programa, y un archivo **hay que
abrirlo antes y cerrarlo después**.

## Ya usas "archivos" sin saberlo

Para el sistema operativo, el teclado y la pantalla también son archivos, solo que siempre
están abiertos:

| | De dónde salen o a dónde van los datos | Quién lo abre |
|---|---|---|
| `cin` | Del teclado | Ya viene abierto |
| `cout` | A la pantalla | Ya viene abierto |
| Un archivo de entrada | De un archivo en el disco | Tu programa |
| Un archivo de salida | A un archivo en el disco | Tu programa |

Por eso, una vez abierto, un archivo se usa **con los mismos operadores**: `<<` para escribir y
`>>` para leer.

## Los tres pasos

Todo trabajo con un archivo sigue el mismo orden:

1. **Abrir.** Se asocia un nombre de archivo (por ejemplo, `"saludo.txt"`) con una variable del
   programa, y se indica si se va a **escribir** o a **leer**.
2. **Usar.** Se escribe con `<<` o se lee con `>>`, igual que con `cout` y `cin`.
3. **Cerrar.** Se le avisa al sistema operativo que el programa terminó con el archivo, para que
   guarde todo lo pendiente y libere los recursos.

## Un primer programa completo

Este programa hace los tres pasos dos veces: primero **escribe** una frase en `saludo.txt` y
después **lee** ese mismo archivo, palabra por palabra.

```cpp
#include <iostream>
#include <fstream>
#include <string>
using namespace std;

int main() {
    // Escribir: abrir, usar, cerrar
    ofstream salida("saludo.txt");
    salida << "Hola desde un archivo" << endl;
    salida.close();

    // Leer: abrir, usar, cerrar
    ifstream entrada("saludo.txt");
    string palabra;
    int palabras = 0;
    while (entrada >> palabra) {
        cout << palabra << endl;
        palabras++;
    }
    entrada.close();

    cout << "Palabras leidas: " << palabras << endl;
    return 0;
}
```

Salida:

```
Hola
desde
un
archivo
Palabras leidas: 4
```

Y en la carpeta del programa aparece `saludo.txt`, con este contenido:

```
Hola desde un archivo
```

Algunos detalles que se explican a fondo más adelante:

- `#include <fstream>` es la biblioteca de archivos, igual que `<iostream>` lo es de `cin` y
  `cout`.
- `ofstream` es un archivo para **escribir** y `ifstream` es un archivo para **leer**
  ([4.8](4.8-ficheros-en-cpp.md)).
- `entrada >> palabra` lee una palabra a la vez, y el `while` se detiene cuando ya no hay más
  ([4.6](4.6-flujo-de-datos.md)).
- `close()` es el tercer paso; por qué importa se ve en [4.7](4.7-memoria-intermedia.md).

## Autocheck

**¿Qué tienen en común `cout << "Hola";` y `salida << "Hola";`?**

Usan el mismo operador, `<<`, para escribir. La diferencia es el destino: `cout` escribe en la
pantalla y `salida` en el archivo con el que se abrió.

**¿Cuáles son los tres pasos para trabajar con un archivo y cuál de ellos no hace falta con
`cin`?**

Abrir, usar y cerrar. Con `cin` no hace falta abrir ni cerrar, porque el teclado ya está
abierto desde que empieza el programa.

**En el programa de ejemplo, ¿por qué el archivo se lee palabra por palabra y no como una sola
frase?**

Porque `>>` lee hasta el siguiente espacio o salto de renglón, igual que `cin >>`, así que cada
vuelta del `while` obtiene una sola palabra.

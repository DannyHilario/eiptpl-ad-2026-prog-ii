# 4.8 Ficheros en C++

*Anterior: [4.7 Memoria intermedia](4.7-memoria-intermedia.md) — Siguiente: [4.9 Modos de apertura](4.9-modos-de-apertura.md)*

Ya viste los conceptos; ahora, la parte práctica. Para usar archivos se incluye la biblioteca
`fstream` y se declara una variable de uno de estos tipos:

| Tipo | Para qué | Se usa como |
|---|---|---|
| `ofstream` | **Escribir** en un archivo (*output file stream*) | `cout`, con `<<` |
| `ifstream` | **Leer** de un archivo (*input file stream*) | `cin`, con `>>` |
| `fstream` | Leer y escribir el mismo archivo | Los dos; no lo usaremos en el curso |

## Escribir en un archivo

```cpp
#include <iostream>
#include <fstream>
using namespace std;

int main() {
    const int NUMERO = 7;

    ofstream archivo("tabla7.txt");
    if (!archivo) {
        cout << "No se pudo crear el archivo." << endl;
        return 1;
    }

    for (int i = 1; i <= 10; i++) {
        archivo << NUMERO << " x " << i << " = " << NUMERO * i << endl;
    }
    archivo.close();

    cout << "Listo: abre tabla7.txt para ver la tabla." << endl;
    return 0;
}
```

En la pantalla solo aparece el aviso:

```
Listo: abre tabla7.txt para ver la tabla.
```

La tabla quedó en `tabla7.txt`; ábrelo con el Bloc de notas:

```
7 x 1 = 7
7 x 2 = 14
7 x 3 = 21
7 x 4 = 28
7 x 5 = 35
7 x 6 = 42
7 x 7 = 49
7 x 8 = 56
7 x 9 = 63
7 x 10 = 70
```

Línea por línea:

- `ofstream archivo("tabla7.txt");` **abre** (o crea) el archivo para escribir. `archivo` es el
  nombre de la variable en el programa; `"tabla7.txt"` es el nombre del archivo en el disco. Si
  el archivo ya existía, **se borra su contenido** y se empieza de cero (en
  [4.9](4.9-modos-de-apertura.md) verás cómo agregar sin borrar).
- `if (!archivo)` comprueba si se pudo abrir. Escribir en una carpeta sin permiso o en una USB
  que se retiró, por ejemplo, hace que falle. Si falla, el programa avisa y termina con
  `return 1;` (un `return` distinto de 0 indica que el programa terminó con un error).
- `archivo << ...` escribe exactamente como `cout <<`, incluido `endl` para el salto de
  renglón.
- `archivo.close();` **cierra** el archivo y pasa al disco lo que quedaba en el buffer.

## Leer de un archivo

Crea con el Bloc de notas un archivo `calificaciones.txt` en la misma carpeta que tu `.exe`, con
un alumno por renglón:

```
Sofia 9.5
Diego 7
Ana 8.25
Luis 6
```

Este programa lo lee, registro por registro, y calcula el promedio:

```cpp
#include <iostream>
#include <fstream>
#include <string>
using namespace std;

int main() {
    ifstream archivo("calificaciones.txt");
    if (!archivo) {
        cout << "No se encontro calificaciones.txt" << endl;
        return 1;
    }

    string nombre;
    double calificacion;
    int alumnos = 0;
    double suma = 0;

    // Cada vuelta lee un registro completo: nombre y calificacion
    while (archivo >> nombre >> calificacion) {
        cout << nombre << ": " << calificacion << endl;
        suma += calificacion;
        alumnos++;
    }
    archivo.close();

    if (alumnos > 0) {
        cout << "Alumnos: " << alumnos << endl;
        cout << "Promedio: " << suma / alumnos << endl;
    } else {
        cout << "El archivo esta vacio." << endl;
    }
    return 0;
}
```

Salida:

```
Sofia: 9.5
Diego: 7
Ana: 8.25
Luis: 6
Alumnos: 4
Promedio: 7.6875
```

Y si el archivo no existe (por ejemplo, porque está en otra carpeta o tiene otro nombre):

```
No se encontro calificaciones.txt
```

Las claves de la lectura:

- `ifstream archivo("calificaciones.txt");` abre el archivo para leer. Si **no existe**, la
  apertura falla y `!archivo` es verdadero: por eso siempre se comprueba.
- `while (archivo >> nombre >> calificacion)` lee un registro en cada vuelta. La condición es
  verdadera mientras la lectura funciona y se vuelve falsa en cuanto ya no hay datos que leer.
  No hace falta saber cuántos renglones tiene el archivo.
- El programa no sabe cuántos alumnos hay: los **cuenta** mientras lee, igual que el contador
  de registros de la Etapa III.

## Por qué no usar `eof()`

En muchos ejemplos (incluido el manual) se lee con `while (!archivo.eof())`. `eof()` significa
*end of file*, fin de archivo. Parece lógico, pero da **una vuelta de más**: `eof()` solo se
vuelve verdadero **después** de que una lectura intentó pasar del final, así que la última
vuelta procesa un dato que no existe. Con un archivo `numeros.txt` que tiene 10, 20 y 30:

```cpp
#include <iostream>
#include <fstream>
using namespace std;

int main() {
    ifstream archivo("numeros.txt");
    int numero;
    int vueltas = 0;

    while (!archivo.eof()) {     // NO conviene: da una vuelta de mas
        archivo >> numero;
        vueltas++;
        cout << "Vuelta " << vueltas << ": " << numero << endl;
    }
    archivo.close();
    return 0;
}
```

Salida:

```
Vuelta 1: 10
Vuelta 2: 20
Vuelta 3: 30
Vuelta 4: 30
```

La vuelta 4 no corresponde a ningún número del archivo: la lectura falló y `numero` se quedó
con lo que tenía (según el compilador, también puede aparecer un 0). Si el programa sumara o
contara, el resultado saldría mal. Con `while (archivo >> numero)` la lectura y la revisión
son una sola cosa y eso no pasa.

## Dónde queda el archivo

Con un nombre sin carpeta, como `"tabla7.txt"`, el archivo se crea y se busca en la **carpeta
de trabajo** del programa. En Dev-C++ es la carpeta donde se genera el `.exe`, que normalmente
es la misma de tu `.cpp`. Si tu programa dice que no encuentra un archivo que sí creaste,
revisa primero que esté en esa carpeta y que el nombre sea exactamente el mismo (el Bloc de
notas a veces agrega `.txt` de más: `datos.txt.txt`).

## Si el nombre del archivo está en un `string`

En el Dev-C++ que usamos (C++98), el nombre del archivo debe ser texto entre comillas o, si
está en una variable `string`, hay que agregarle `.c_str()`:

```cpp
const string ARCHIVO = "inventario.txt";
ifstream entrada(ARCHIVO.c_str());    // en C++98 hace falta .c_str()
```

`.c_str()` entrega el texto del `string` en el formato antiguo que piden los archivos en
C++98. En versiones más nuevas de C++ ya no hace falta, pero con él el programa funciona en
cualquier versión.

## Autocheck

**¿Qué tipo usas para leer un archivo y cuál para escribirlo?**

`ifstream` para leer (se usa como `cin`) y `ofstream` para escribir (se usa como `cout`).

**Ejecutas dos veces el programa de la tabla del 7. ¿Cuántas tablas tiene `tabla7.txt` al
final?**

Una sola: al abrir con `ofstream` en el modo normal, el contenido anterior se borra.

**¿Qué pasa si abres con `ifstream` un archivo que no existe y por qué hay que comprobarlo con
`if (!archivo)`?**

La apertura falla. Si no se comprueba, el `while` no lee nada y el programa sigue como si el
archivo estuviera vacío, sin avisar del problema.

**El archivo de calificaciones tiene 4 alumnos. ¿Cuántas vueltas da `while (archivo >> nombre >>
calificacion)` y cuántas daría con `while (!archivo.eof())`?**

Con `>>` en la condición, 4 vueltas. Con `eof()`, 5: la última procesa un registro que no
existe.

**¿Qué falta en esta línea para que compile en Dev-C++ con C++98:
`ofstream salida(NOMBRE);`, si `NOMBRE` es un `string`?**

`.c_str()`: `ofstream salida(NOMBRE.c_str());`

# 2.7 Ordenamiento por inserción

*Anterior: [2.6 Búsqueda lineal](2.6-busqueda-lineal.md) — Siguiente: [2.8 Ordenamiento burbuja](2.8-ordenamiento-burbuja.md)*

**Ordenar** un arreglo significa reacomodar sus elementos según un criterio (por
ejemplo, ascendente). El **ordenamiento por inserción** es uno de los métodos más
simples de programar: separa el arreglo en una parte "ya ordenada" (al inicio) y una
parte "por procesar" (el resto), y en cada paso toma el siguiente elemento sin
ordenar y lo **inserta** en el lugar correcto dentro de la parte ya ordenada.

```cpp
#include <iostream>
using namespace std;

int main() {
    const int N = 6;
    int datos[N] = {23, 5, 41, 9, 17, 2};

    for (int i = 1; i < N; i++) {
        int insertar = datos[i];
        int j = i - 1;

        while (j >= 0 && datos[j] > insertar) {
            datos[j + 1] = datos[j];
            j--;
        }
        datos[j + 1] = insertar;
    }

    cout << "Arreglo ordenado: ";
    for (int i = 0; i < N; i++) {
        cout << datos[i] << " ";
    }
    cout << endl;

    return 0;
}
```

Salida:

```
Arreglo ordenado: 2 5 9 17 23 41
```

## Traza paso a paso

Partiendo de `[23, 5, 41, 9, 17, 2]` (el elemento en la posición 0 se considera "ya
ordenado" de entrada, porque un solo elemento siempre está ordenado consigo mismo):

| `i` | elemento a insertar | arreglo después de esta vuelta |
|---|---|---|
| 1 | 5 | `[5, 23, 41, 9, 17, 2]` |
| 2 | 41 | `[5, 23, 41, 9, 17, 2]` (ya estaba en su lugar) |
| 3 | 9 | `[5, 9, 23, 41, 17, 2]` |
| 4 | 17 | `[5, 9, 17, 23, 41, 2]` |
| 5 | 2 | `[2, 5, 9, 17, 23, 41]` |

## Cómo funciona el código

- `insertar = datos[i]` guarda temporalmente el valor que se va a acomodar, porque el
  ciclo `while` va a ir recorriendo (y sobrescribiendo) posiciones hacia atrás.
- `j = i - 1` arranca justo en el último elemento de la parte ya ordenada.
- El `while` se repite mientras **todavía haya elementos a la izquierda** (`j >= 0`)
  **y** el elemento en `datos[j]` sea mayor que `insertar`: en cada vuelta, recorre
  ese elemento un lugar a la derecha (`datos[j + 1] = datos[j]`) para abrirle espacio
  a `insertar`, y retrocede `j`.
- Cuando el `while` termina — porque ya no hay más elementos a la izquierda, o porque
  encontró uno que **no** es mayor que `insertar` — la posición correcta para
  `insertar` es `j + 1`, y ahí se coloca.

## Por qué es fácil de programar pero lento

La ventaja del ordenamiento por inserción es lo simple que es de escribir y de seguir
mentalmente. Su desventaja es la velocidad: para cada elemento nuevo, en el peor caso
tiene que compararlo (y desplazar) contra todos los elementos ya ordenados a su
izquierda. Con arreglos pequeños esto no se nota, pero se vuelve notablemente lento
con arreglos grandes.

## Autocheck

**¿Por qué el ciclo externo (`for`) empieza en `i = 1` y no en `i = 0`?**

Porque un solo elemento (`datos[0]`) ya cuenta como "ordenado" por definición — no
hay nada contra qué compararlo todavía. El primer elemento que realmente hay que
insertar en su lugar es `datos[1]`.

**En la traza, ¿por qué el arreglo no cambia en la vuelta `i = 2` (insertar 41)?**

Porque 41 ya es mayor que todo lo que está a su izquierda (`5` y `23`), así que la
condición `datos[j] > insertar` del `while` es falsa desde la primera comparación —
el ciclo `while` no se ejecuta ninguna vez, y 41 se "inserta" en la misma posición
donde ya estaba.

**¿Qué guarda la variable `insertar` y por qué es necesaria?**

Guarda una copia del valor que se va a acomodar, tomado antes de que el `while`
empiece a mover elementos. Es necesaria porque el `while` sobrescribe `datos[i]` al
desplazar elementos hacia la derecha — sin guardar antes ese valor, se perdería.

# 2.8 Ordenamiento burbuja

*Anterior: [2.7 Ordenamiento por inserción](2.7-ordenamiento-por-insercion.md)*

El **ordenamiento burbuja** (*bubble sort*) es otro método simple de ordenar un
arreglo: recorre el arreglo comparando **cada elemento con el siguiente**, e
intercambia los dos si están en el orden equivocado. Repitiendo este recorrido varias
veces, los valores más grandes van "flotando" hacia el final — de ahí el nombre.

```cpp
#include <iostream>
using namespace std;

int main() {
    const int N = 6;
    int datos[N] = {23, 5, 41, 9, 17, 2};

    for (int vuelta = 0; vuelta < N - 1; vuelta++) {
        for (int i = 0; i < N - 1 - vuelta; i++) {
            if (datos[i] > datos[i + 1]) {
                int temporal = datos[i];
                datos[i] = datos[i + 1];
                datos[i + 1] = temporal;
            }
        }
    }

    cout << "Arreglo ordenado: ";
    for (int i = 0; i < N; i++) {
        cout << datos[i] << " ";
    }
    cout << endl;

    return 0;
}
```

Salida:

```
Arreglo ordenado: 2 5 9 17 23 41
```

## Traza paso a paso

Partiendo de `[23, 5, 41, 9, 17, 2]`, cada "vuelta" del ciclo externo compara pares
consecutivos de izquierda a derecha e intercambia los que están mal ordenados:

| vuelta | comparaciones e intercambios | arreglo al final de la vuelta |
|---|---|---|
| 0 | 23↔5, 41↔9, 41↔17, 41↔2 | `[5, 23, 9, 17, 2, 41]` |
| 1 | 23↔9, 23↔17, 23↔2 | `[5, 9, 17, 2, 23, 41]` |
| 2 | 17↔2 | `[5, 9, 2, 17, 23, 41]` |
| 3 | 9↔2 | `[5, 2, 9, 17, 23, 41]` |
| 4 | 5↔2 | `[2, 5, 9, 17, 23, 41]` |

Nota cómo, después de la vuelta 0, el `41` (el valor más grande) ya quedó al final —
y se queda ahí en todas las vueltas siguientes, porque ya está en su posición final.
Eso es justo lo que hace `N - 1 - vuelta` en el ciclo interno: en cada vuelta nueva,
ya no hace falta revisar la última posición, porque ya quedó ordenada.

## Cómo funciona el código

- El ciclo externo (`vuelta`) controla **cuántas veces** se recorre el arreglo
  completo — en el peor caso, `N - 1` veces son suficientes para garantizar que todo
  quede ordenado.
- El ciclo interno (`i`) compara `datos[i]` con su vecino `datos[i + 1]`, e
  intercambia ambos usando una variable `temporal` si están en el orden incorrecto —
  el patrón clásico de intercambio de dos variables.
- El límite `N - 1 - vuelta` del ciclo interno se va **reduciendo** en cada vuelta,
  porque cada vuelta empuja un valor más a su posición final al extremo derecho, y ya
  no hace falta volver a compararlo.

## Comparación rápida con inserción

Burbuja e inserción resuelven el mismo problema con una idea de fondo distinta:
inserción **inserta** cada elemento nuevo en su lugar dentro de una porción ya
ordenada, mientras que burbuja **compara e intercambia vecinos** repetidamente hasta
que no queden desórdenes. Ambos son fáciles de programar y ambos son lentos en
arreglos grandes — este curso no cubre métodos más rápidos, pero es bueno saber que
existen (quicksort, mergesort, entre otros) para cuando avances más en programación.

## Autocheck

**¿Por qué el límite del ciclo interno es `N - 1 - vuelta` y no simplemente
`N - 1`?**

Porque cada vuelta completa del ciclo externo garantiza que el valor más grande
restante ya quedó en su posición final, al extremo derecho — no hace falta volver a
compararlo en las vueltas siguientes, así que el límite se reduce en 1 por cada
vuelta.

**En la traza, ¿por qué el `41` ya no se vuelve a mover después de la vuelta 0?**

Porque en la vuelta 0 ya llegó hasta el final del arreglo (la posición más a la
derecha), que es donde le corresponde estar como valor más grande — y el límite
decreciente del ciclo interno hace que las vueltas siguientes ya no lo toquen.

**¿Qué hace la variable `temporal` en el intercambio?**

Guarda momentáneamente el valor de `datos[i]` antes de sobrescribirlo, para no
perderlo: sin esa copia, la línea `datos[i] = datos[i + 1]` destruiría el valor
original de `datos[i]` antes de poder asignarlo a `datos[i + 1]`.

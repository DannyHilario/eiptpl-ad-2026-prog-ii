# 2.5 Arreglos de caracteres

*Anterior: [2.4 Recorrido con for](2.4-recorrido-con-for.md) — Siguiente: [2.6 Búsqueda lineal](2.6-busqueda-lineal.md)*

Ya usaste `string` para guardar texto — es cómodo y evita varios errores comunes.
Pero en C++, una cadena de texto también se puede representar como lo que es "por
debajo": un **arreglo de `char`**. Vale la pena entenderlo, porque tarde o temprano
te vas a topar con código (o con herramientas de C++) que trabaja así en vez de con
`string`.

## El carácter nulo `'\0'`

Un arreglo de `char` que representa una cadena termina con un carácter especial
invisible: el **carácter nulo**, escrito `'\0'`. Es lo que le indica a funciones como
`cout` dónde termina el texto.

```cpp
char saludo[] = "hola";
```

Aunque `"hola"` tiene 4 letras, este arreglo en realidad tiene **5** elementos:
`'h'`, `'o'`, `'l'`, `'a'` y `'\0'` al final. Esto es equivalente a escribirlo con
una lista de caracteres:

```cpp
char saludo[] = {'h', 'o', 'l', 'a', '\0'};
```

Si al construir un arreglo de caracteres a mano se te olvida el `'\0'` final, ese
arreglo deja de representar una cadena válida — funciones como `cout` seguirían
imprimiendo caracteres de la memoria contigua hasta toparse con un `'\0'` por
casualidad, un error muy difícil de rastrear.

## Acceso por índice, igual que cualquier arreglo

Como es un arreglo, se puede acceder a cada carácter individual con `[ ]`:

```cpp
#include <iostream>
using namespace std;

int main() {
    char saludo[] = "hola";

    cout << "saludo completo: " << saludo << endl;
    cout << "saludo[0] = " << saludo[0] << endl;
    cout << "saludo[3] = " << saludo[3] << endl;
    cout << "tamano del arreglo (con \\0 incluido): " << sizeof(saludo) << endl;

    return 0;
}
```

Salida:

```
saludo completo: hola
saludo[0] = h
saludo[3] = a
tamano del arreglo (con \0 incluido): 5
```

## Leer e imprimir un arreglo de caracteres

`cin >>` y `cout <<` funcionan con arreglos de `char` igual que con `string`, pero
con una diferencia importante: **`cin >> arreglo` no sabe qué tan grande es el
arreglo** — solo lee caracteres hasta el primer espacio en blanco y agrega el `'\0'`
al final. Es responsabilidad del programador declarar el arreglo con espacio
suficiente para lo que el usuario pueda escribir; si el usuario escribe más
caracteres de los que el arreglo puede contener, `cin >>` escribe de todas formas
más allá del arreglo, con el mismo riesgo de comportamiento indefinido que viste en
[2.2 Creación de arrays](2.2-creacion-de-arrays.md).

```cpp
#include <iostream>
using namespace std;

int main() {
    char palabra[20];

    cout << "Escribe una palabra: ";
    cin >> palabra;

    cout << "La escribiste asi: " << palabra << endl;

    cout << "Caracter por caracter: ";
    for (int i = 0; palabra[i] != '\0'; i++) {
        cout << palabra[i] << " ";
    }
    cout << endl;

    return 0;
}
```

Con la entrada `programacion`, imprime:

```
Escribe una palabra: La escribiste asi: programacion
Caracter por caracter: p r o g r a m a c i o n
```

La condición `palabra[i] != '\0'` en el `for` es la forma típica de recorrer un
arreglo de caracteres sin conocer de antemano cuántos caracteres válidos tiene — el
ciclo se detiene exactamente donde termina la cadena real, sin importar qué tan
grande se declaró el arreglo.

## Autocheck

**¿Cuántos elementos tiene realmente el arreglo `char clave[] = "abc";`?**

4 — las tres letras más el carácter nulo `'\0'` que el compilador agrega
automáticamente al final.

**¿Por qué la condición `palabra[i] != '\0'` es la forma correcta de recorrer un
arreglo de caracteres, en vez de usar un tamaño fijo como `i < 20`?**

Porque el arreglo puede tener espacio para 20 caracteres pero contener una palabra
mucho más corta — el `'\0'` marca exactamente dónde termina el texto real,
independientemente del tamaño declarado del arreglo.

**¿Qué pasa si el arreglo `char palabra[20]` recibe con `cin >>` una entrada de 30
caracteres sin espacios?**

`cin >>` no verifica el tamaño del arreglo: escribiría los 30 caracteres de todas
formas, más allá del límite del arreglo — el mismo riesgo de comportamiento
indefinido de cualquier acceso fuera de rango en un arreglo.

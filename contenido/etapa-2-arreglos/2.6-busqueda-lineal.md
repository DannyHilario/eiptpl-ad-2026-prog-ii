# 2.6 Búsqueda lineal

*Anterior: [2.5 Arreglos de caracteres](2.5-arreglos-de-caracteres.md) — Siguiente: [2.7 Ordenamiento por inserción](2.7-ordenamiento-por-insercion.md)*

**Buscar** en un arreglo significa determinar si contiene un valor específico y, si
es así, en qué posición está. La forma más simple de hacerlo es la **búsqueda
lineal**: revisar los elementos uno por uno, en orden, comparando cada uno con el
valor buscado (la **clave**), hasta encontrarlo o hasta acabarse el arreglo.

```cpp
#include <iostream>
using namespace std;

int main() {
    const int N = 8;
    int numeros[N] = {23, 5, 41, 9, 17, 33, 2, 8};
    int clave;
    int posicion = -1;

    cout << "Numero a buscar: ";
    cin >> clave;

    for (int i = 0; i < N; i++) {
        if (numeros[i] == clave) {
            posicion = i;
            break;
        }
    }

    if (posicion != -1) {
        cout << clave << " se encontro en la posicion " << posicion << endl;
    } else {
        cout << clave << " no esta en el arreglo" << endl;
    }

    return 0;
}
```

Con la entrada `17`, imprime `17 se encontro en la posicion 4`. Con la entrada `99`,
imprime `99 no esta en el arreglo`.

## Cómo funciona

- `posicion` arranca en `-1`, un valor que **no puede ser** un índice válido —
  funciona como bandera para saber si el elemento se encontró o no.
- El `for` recorre el arreglo comparando cada elemento contra `clave`. En cuanto
  encuentra una coincidencia, guarda el índice en `posicion` y usa `break` para
  **salir del ciclo de inmediato** — no tiene caso seguir comparando una vez que ya
  se encontró lo que se buscaba.
- Si el ciclo termina sin que ninguna comparación haya sido verdadera, `posicion`
  sigue en `-1`, y eso es lo que se revisa al final para decidir el mensaje.

## Cuándo conviene (y cuándo no)

La búsqueda lineal funciona sin importar el orden del arreglo — no necesita que los
datos estén ordenados. Su costo es que, en el peor caso (el valor buscado no está, o
está hasta el final), tiene que comparar contra **todos** los elementos del
arreglo. Para arreglos pequeños esto no importa, pero para arreglos muy grandes
existen métodos más rápidos (como la búsqueda binaria) que solo funcionan si el
arreglo ya está ordenado — algo que veremos con los métodos de ordenamiento de las
siguientes dos sesiones.

## Autocheck

**¿Por qué `posicion` se inicializa en `-1` y no en `0`?**

Porque `0` sí es un índice válido (el primer elemento) y se confundiría con "se
encontró en la posición 0". `-1` nunca es un índice real de un arreglo, así que sirve
como señal clara de "todavía no se encuentra" o "no está".

**¿Qué pasaría si se quita el `break` del ciclo?**

El programa seguiría funcionando igual si la clave aparece una sola vez, pero seguiría
comparando innecesariamente el resto del arreglo después de encontrarla — trabajo de
más. Si la clave apareciera más de una vez, `posicion` terminaría con el índice de la
**última** aparición en vez de la primera.

**¿La búsqueda lineal necesita que el arreglo esté ordenado para funcionar?**

No. Funciona sobre cualquier arreglo, ordenado o no, porque compara elemento por
elemento sin asumir ningún orden particular.

# 2.4 Recorrido con for

*Anterior: [2.3 Inicialización de arrays](2.3-inicializacion-de-arrays.md) — Siguiente: [2.5 Arreglos de caracteres](2.5-arreglos-de-caracteres.md)*

La forma casi universal de procesar un arreglo es recorrerlo con un `for`, usando el
índice del ciclo para acceder a cada elemento. Esta sesión son puros ejemplos —
la mecánica ya la conoces desde `for`; lo nuevo es combinarla con `[i]`.

## Ejemplo 1: suma de los elementos de un vector

```cpp
#include <iostream>
using namespace std;

int main() {
    const int N = 5;
    int numeros[N];
    int suma = 0;

    for (int i = 0; i < N; i++) {
        cout << "Numero " << (i + 1) << ": ";
        cin >> numeros[i];
    }

    for (int i = 0; i < N; i++) {
        suma += numeros[i];
    }

    cout << "La suma es: " << suma << endl;

    return 0;
}
```

Con la entrada `5 3 9 2 7`, este programa imprime `La suma es: 26`. Nota que se usan
**dos** ciclos `for` separados: uno para leer los datos y otro para procesarlos.
Podrían combinarse en uno solo, pero separarlos deja más claro qué hace cada parte —
más adelante vas a ver casos donde sí conviene combinarlos.

## Ejemplo 2: el mayor de un vector

```cpp
#include <iostream>
using namespace std;

int main() {
    const int N = 5;
    int numeros[N];

    for (int i = 0; i < N; i++) {
        cout << "Numero " << (i + 1) << ": ";
        cin >> numeros[i];
    }

    int mayor = numeros[0];
    for (int i = 1; i < N; i++) {
        if (numeros[i] > mayor) {
            mayor = numeros[i];
        }
    }

    cout << "El mayor es: " << mayor << endl;

    return 0;
}
```

Con la entrada `5 3 9 2 7`, imprime `El mayor es: 9`. El patrón es: **arranca
suponiendo que el primer elemento es el mayor**, y luego compara cada elemento
restante contra ese "mayor hasta ahora" — por eso el segundo `for` empieza en `i = 1`
y no en `i = 0` (comparar `numeros[0]` contra sí mismo sería inútil).

## Recorrido de una matriz: for anidado

Para una matriz se necesita un `for` dentro de otro: el externo recorre las filas, el
interno recorre las columnas de cada fila.

**Ejemplo 3: suma de los elementos de una matriz**

```cpp
#include <iostream>
using namespace std;

int main() {
    const int FILAS = 3;
    const int COLUMNAS = 2;
    int numeros[FILAS][COLUMNAS];
    int suma = 0;

    for (int fila = 0; fila < FILAS; fila++) {
        for (int columna = 0; columna < COLUMNAS; columna++) {
            cout << "numeros[" << fila << "][" << columna << "]: ";
            cin >> numeros[fila][columna];
        }
    }

    for (int fila = 0; fila < FILAS; fila++) {
        for (int columna = 0; columna < COLUMNAS; columna++) {
            suma += numeros[fila][columna];
        }
    }

    cout << "La suma de los " << (FILAS * COLUMNAS) << " numeros es: " << suma << endl;

    return 0;
}
```

Con la entrada `1 2 3 4 5 6`, imprime `La suma de los 6 numeros es: 21`.

**Ejemplo 4: contar pares e impares en una matriz**

```cpp
#include <iostream>
using namespace std;

int main() {
    const int FILAS = 3;
    const int COLUMNAS = 2;
    int numeros[FILAS][COLUMNAS];
    int pares = 0;
    int impares = 0;

    for (int fila = 0; fila < FILAS; fila++) {
        for (int columna = 0; columna < COLUMNAS; columna++) {
            cout << "numeros[" << fila << "][" << columna << "]: ";
            cin >> numeros[fila][columna];
        }
    }

    for (int fila = 0; fila < FILAS; fila++) {
        for (int columna = 0; columna < COLUMNAS; columna++) {
            if (numeros[fila][columna] % 2 == 0) {
                pares++;
            } else {
                impares++;
            }
        }
    }

    cout << "Pares: " << pares << ", Impares: " << impares << endl;

    return 0;
}
```

Con la entrada `1 2 3 4 5 6`, imprime `Pares: 3, Impares: 3`.

## Autocheck

**En el Ejemplo 2, ¿por qué el ciclo que busca el mayor empieza en `i = 1` y no en
`i = 0`?**

Porque `mayor` ya se inicializó con `numeros[0]` antes del ciclo — comparar
`numeros[0]` contra sí mismo en la primera vuelta no serviría de nada, así que el
recorrido de comparación empieza en el siguiente elemento.

**Para recorrer una matriz de `FILAS` por `COLUMNAS`, ¿cuántos ciclos `for` se
necesitan como mínimo y por qué?**

Dos, uno anidado dentro del otro: el externo avanza fila por fila, y el interno
recorre las columnas de esa fila antes de que el externo pase a la siguiente.

**Si en el Ejemplo 3 cambias `FILAS` a 4 sin cambiar nada más, ¿qué pasa?**

El programa pide y suma 8 números en vez de 6 (`FILAS * COLUMNAS`), porque ambos
ciclos `for` usan las constantes `FILAS` y `COLUMNAS` en su condición — no hay
números fijos que ajustar aparte.

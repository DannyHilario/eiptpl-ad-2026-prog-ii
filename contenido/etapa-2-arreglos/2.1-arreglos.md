# 2.1 Arreglos

*Anterior: [1.4 Reglas de alcance](../etapa-1-funciones/1.4-reglas-de-alcance.md) — Siguiente: [2.2 Creación de arrays](2.2-creacion-de-arrays.md)*

Hasta ahora, cada variable que has declarado guarda **un solo valor**: una nota, una
edad, un nombre. Pero muchos problemas reales trabajan con **colecciones** de datos
relacionados: las notas de un grupo completo, los participantes de una carrera, las
temperaturas de una semana. Resolver eso con variables sueltas es incómodo y no
escala — imagina promediar las notas de 30 alumnos con 30 variables `double`
distintas.

## El problema con variables sueltas

```cpp
#include <iostream>
using namespace std;

int main() {
    double calificacion1, calificacion2, calificacion3, calificacion4, calificacion5;

    cout << "Calificacion 1: "; cin >> calificacion1;
    cout << "Calificacion 2: "; cin >> calificacion2;
    cout << "Calificacion 3: "; cin >> calificacion3;
    cout << "Calificacion 4: "; cin >> calificacion4;
    cout << "Calificacion 5: "; cin >> calificacion5;

    double suma = calificacion1 + calificacion2 + calificacion3 + calificacion4 + calificacion5;
    cout << "Promedio: " << suma / 5 << endl;

    return 0;
}
```

Funciona con 5 calificaciones, pero no hay forma de "recorrerlas" — cada una vive en
una variable con nombre distinto, así que sumarlas significa escribir los 5 nombres a
mano. Con 30 alumnos, esto sería inmanejable.

## Un arreglo agrupa esos valores bajo un solo nombre

Un **arreglo** (*array*) es un conjunto de tamaño fijo de datos del **mismo tipo**,
guardados en memoria uno detrás de otro y accesibles mediante un **índice** numérico
que empieza en 0. El mismo problema, con un arreglo:

```cpp
#include <iostream>
using namespace std;

int main() {
    double calificaciones[5];

    for (int i = 0; i < 5; i++) {
        cout << "Calificacion " << (i + 1) << ": ";
        cin >> calificaciones[i];
    }

    double suma = 0;
    for (int i = 0; i < 5; i++) {
        suma += calificaciones[i];
    }
    cout << "Promedio: " << suma / 5 << endl;

    return 0;
}
```

Los dos programas hacen exactamente lo mismo, pero la versión con arreglo **no
depende del número de calificaciones**: cambiar `5` por `30` en un solo lugar (y en
el `for`) es todo lo que se necesita — no hay que declarar 25 variables nuevas ni
copiar 25 líneas de `cin`.

## Índices: límite inferior y límite superior

Cada elemento de un arreglo se identifica por su índice:

- **Límite inferior (LI):** el índice del primer elemento, siempre `0`.
- **Límite superior (LS):** el índice del último elemento, que es el tamaño del
  arreglo **menos 1**.

En `double calificaciones[5]`, los índices válidos van de `calificaciones[0]` a
`calificaciones[4]` — cinco elementos, no seis. Este "menos 1" es la fuente más común
de errores al empezar con arreglos, así que vale la pena memorizarlo bien desde
ahora.

## Vector, matriz y arreglo multidimensional

Un arreglo puede tener una o más dimensiones:

- **Vector:** una dimensión — una fila de datos (`calificaciones[5]` de arriba).
- **Matriz:** dos dimensiones — filas y columnas, como una tabla
  (`tablero[3][2]` sería una matriz de 3 filas y 2 columnas).
- **Multidimensional:** tres o más dimensiones, poco común en este curso.

Este curso trabaja principalmente con vectores y, ocasionalmente, matrices.

## Operaciones típicas sobre un arreglo

Prácticamente todo lo que se hace con un arreglo se reduce a estas operaciones, que
vas a ver a lo largo de esta etapa:

- **Asignación** — guardar un valor en una posición.
- **Lectura / escritura** — leer o mostrar un valor de una posición.
- **Recorrido** — visitar cada elemento, casi siempre con un `for`.
- **Actualización** — insertar, borrar o modificar elementos.
- **Ordenación** — reacomodar los elementos en un orden (ascendente/descendente).
- **Búsqueda** — encontrar si un valor está presente, y en qué posición.

## Autocheck

**¿Por qué no basta con usar 30 variables `double` sueltas para las notas de un
grupo de 30 alumnos?**

Porque no se pueden recorrer con un `for`: cada variable tiene un nombre distinto, así
que sumarlas o promediarlas significaría escribir los 30 nombres a mano. Un arreglo
resuelve esto porque el índice del `for` reemplaza al nombre.

**Si declaras `int temperaturas[7]`, ¿cuáles son sus índices válidos?**

Del `0` al `6` — siete elementos, límite inferior 0 y límite superior `7 - 1 = 6`.

**¿Qué diferencia hay entre un vector y una matriz?**

El número de dimensiones: un vector tiene una dimensión (una fila de datos), una
matriz tiene dos (filas y columnas).

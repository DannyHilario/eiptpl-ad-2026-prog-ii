# 2.3 Inicialización de arrays

*Anterior: [2.2 Creación de arrays](2.2-creacion-de-arrays.md) — Siguiente: [2.4 Recorrido con for](2.4-recorrido-con-for.md)*

Igual que una variable simple, un arreglo se puede inicializar en la misma línea en
que se declara, en vez de llenarlo después con un `for`.

```cpp
#include <iostream>
using namespace std;

int main() {
    double notas[10] = {8, 9.5, 7, 6.5, 10, 8, 7.5, 9, 6, 10};
    int contador[] = {1, 2, 3, 6};
    int tablero[][3] = {{1, 2, 3}, {4, 5, 6}, {7, 8, 9}};

    cout << "notas[4] = " << notas[4] << endl;
    cout << "contador tiene " << (sizeof(contador) / sizeof(contador[0])) << " elementos" << endl;
    cout << "tablero[2][1] = " << tablero[2][1] << endl;

    return 0;
}
```

Salida:

```
notas[4] = 10
contador tiene 4 elementos
tablero[2][1] = 8
```

## El tamaño se puede omitir si hay lista de valores

Cuando declaras un arreglo **con** una lista de valores inicial, no es obligatorio
especificar el número de elementos entre corchetes — el compilador lo calcula
contando los valores de la lista:

- `double notas[10] = {...}` — aquí sí se dio el tamaño (10), y coincide con los 10
  valores de la lista.
- `int contador[] = {1, 2, 3, 6}` — corchetes vacíos: el compilador infiere que el
  tamaño es 4, porque hay 4 valores.
- `int tablero[][3] = {{1, 2, 3}, {4, 5, 6}, {7, 8, 9}}` — en una matriz, solo se
  puede omitir la **primera** dimensión (el número de filas); las columnas (`3`)
  siempre deben indicarse. Aquí hay 9 valores repartidos en filas de 3, así que el
  compilador infiere 3 filas.

Si das un tamaño explícito **más grande** que la cantidad de valores en la lista
(por ejemplo `int datos[10] = {1, 2, 3};`), los elementos que sobran se inicializan
en `0` automáticamente — pero no puedes dar **menos** valores de los que caben si
intentas forzar un tamaño más chico que la lista; eso sí es un error de compilación.

## Autocheck

**¿Qué tamaño le asigna el compilador a `int valores[] = {4, 8, 15, 16, 23, 42};`?**

6 — el compilador cuenta los 6 valores de la lista y usa ese número como tamaño del
arreglo.

**En `int matriz[][2] = {{1, 2}, {3, 4}, {5, 6}};`, ¿por qué se puede omitir el
número de filas pero no el de columnas?**

Porque el compilador solo puede inferir **una** dimensión a partir del total de
valores — necesita conocer las columnas (2) para poder dividir la lista de 6 valores
en filas completas; sin ese dato no sabría dónde termina cada fila.

**Si declaras `int datos[5] = {1, 2};`, ¿qué valor tienen `datos[2]`, `datos[3]` y
`datos[4]`?**

`0` — cuando el tamaño declarado es mayor que la cantidad de valores en la lista,
los elementos restantes se inicializan automáticamente en cero.

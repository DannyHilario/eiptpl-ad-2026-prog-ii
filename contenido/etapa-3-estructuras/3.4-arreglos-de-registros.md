# 3.4 Arreglos de registros

*Anterior: [3.3 Inicialización de estructuras](3.3-inicializacion-de-estructuras.md)*

Un `struct` guarda los datos de **un** jugador. Un torneo tiene equipos completos. Aquí se
juntan las dos herramientas: un **arreglo de structs** (o arreglo de registros), donde cada
elemento del arreglo es un jugador completo con todos sus campos. Es la forma más común de
usar estructuras y el centro de esta etapa.

## Antes: arreglos paralelos

Con lo que viste en la Etapa II, guardarías un equipo en varios arreglos del mismo tamaño,
uno por dato:

```cpp
string nombres[4];
int goles[4];
int partidos[4];
```

Se llaman **arreglos paralelos**: el jugador `i` está repartido en `nombres[i]`, `goles[i]` y
`partidos[i]`, y lo único que los une es que comparten el mismo índice. Basta un error para
romper esa relación. Por ejemplo, si al ordenar por goles intercambias `goles[i]` con
`goles[i + 1]` pero olvidas intercambiar los nombres, cada jugador queda con los goles de
otro.

## Ahora: un arreglo de structs

```cpp
struct Jugador {
    string nombre;
    int numero;
    int goles;
    int partidos;
};

const int N = 4;
Jugador equipo[N];
```

`equipo` es un arreglo de 4 elementos, y **cada elemento es un `Jugador`** con sus cuatro
campos. Los datos de cada jugador viajan juntos.

## Acceso: primero el índice, luego el campo

```cpp
equipo[2].goles = 12;   // los goles del tercer jugador
```

Se lee de izquierda a derecha: `equipo[2]` es el jugador de la posición 2 (un `Jugador`), y
`.goles` es su campo. El orden importa:

| Expresión | ¿Es correcta? | Por qué |
|---|---|---|
| `equipo[2].goles` | Sí | El jugador 2, su campo `goles` |
| `equipo.goles[2]` | No compila | `equipo` es un arreglo, no tiene campo `goles`; y `goles` no es un arreglo |
| `equipo[2]` | Sí, pero es el struct completo | Sirve para copiarlo (`Jugador x = equipo[2];`), no para imprimirlo con `cout` |

## Inicializar un arreglo de structs

Se combinan las dos formas de inicializar: llaves para el arreglo y, adentro, llaves para
cada struct, en el orden de sus campos.

```cpp
Jugador equipo[N] = {
    {"Sofia", 10, 9, 6},
    {"Diego", 7, 4, 5},
    {"Ana", 9, 12, 8},
    {"Luis", 3, 0, 4}
};
```

Y `Jugador equipo[N] = {};` deja a todos los jugadores con sus campos en cero y sus nombres
vacíos.

## Ejemplo completo: estadísticas de un equipo

El programa captura los datos de 4 jugadores, muestra una tabla con los goles por partido de
cada uno, el total de goles del equipo y quién es el goleador.

```cpp
#include <iostream>
#include <string>
using namespace std;

struct Jugador {
    string nombre;
    int numero;
    int goles;
    int partidos;
};

double calcularPromedio(int goles, int partidos);

int main() {
    const int N = 4;
    Jugador equipo[N] = {};

    for (int i = 0; i < N; i++) {
        cout << "Jugador " << (i + 1) << endl;
        cout << "  Nombre: ";
        cin >> equipo[i].nombre;
        cout << "  Numero de playera: ";
        cin >> equipo[i].numero;

        do {
            cout << "  Goles (0 o mas): ";
            cin >> equipo[i].goles;
            if (equipo[i].goles < 0) {
                cout << "  ERROR! No puede ser negativo." << endl;
            }
        } while (equipo[i].goles < 0);

        do {
            cout << "  Partidos jugados (1 o mas): ";
            cin >> equipo[i].partidos;
            if (equipo[i].partidos < 1) {
                cout << "  ERROR! Debe haber jugado al menos 1 partido." << endl;
            }
        } while (equipo[i].partidos < 1);
    }

    int totalGoles = 0;
    int goleador = 0;   // posicion del goleador; arranca suponiendo que es el primero

    cout << endl << "#\tNombre\tGoles\tPartidos\tGoles por partido" << endl;
    for (int i = 0; i < N; i++) {
        cout << equipo[i].numero << "\t" << equipo[i].nombre << "\t"
             << equipo[i].goles << "\t" << equipo[i].partidos << "\t\t"
             << calcularPromedio(equipo[i].goles, equipo[i].partidos) << endl;

        totalGoles += equipo[i].goles;
        if (equipo[i].goles > equipo[goleador].goles) {
            goleador = i;
        }
    }

    cout << endl << "Total de goles del equipo: " << totalGoles << endl;
    cout << "Goleador: " << equipo[goleador].nombre
         << " (#" << equipo[goleador].numero << ") con "
         << equipo[goleador].goles << " goles" << endl;

    return 0;
}

double calcularPromedio(int goles, int partidos) {
    return (double) goles / partidos;
}
```

Con la entrada de los cuatro jugadores del ejemplo de inicialización (`Sofia 10 9 6`,
`Diego 7 4 5`, `Ana 9 12 8`, `Luis 3 0 4`), la tabla y el resumen quedan así:

```
#	Nombre	Goles	Partidos	Goles por partido
10	Sofia	9	6		1.5
7	Diego	4	5		0.8
9	Ana	12	8		1.5
3	Luis	0	4		0

Total de goles del equipo: 25
Goleador: Ana (#9) con 12 goles
```

Tres detalles del programa:

- **El goleador se guarda como posición** (`goleador = i`), no como número de goles. Con la
  posición tienes acceso a **todos** sus datos (`equipo[goleador].nombre`,
  `equipo[goleador].numero`), igual que en la búsqueda del mayor de
  [2.4](../etapa-2-arreglos/2.4-recorrido-con-for.md).
- **La validación de `partidos` evita dividir entre cero** en `calcularPromedio`.
- **`calcularPromedio` recibe campos sueltos** (`int`, `int`), como en
  [3.3](3.3-inicializacion-de-estructuras.md): sigue siendo una función pura.

## La ventaja al ordenar

Con arreglos paralelos, ordenar por goles con burbuja
([2.8](../etapa-2-arreglos/2.8-ordenamiento-burbuja.md)) obliga a intercambiar **cada**
arreglo por separado. Con un arreglo de structs, se intercambia el jugador completo de una
sola vez, porque `=` copia todos los campos:

```cpp
for (int pasada = 0; pasada < N - 1; pasada++) {
    for (int j = 0; j < N - 1 - pasada; j++) {
        if (equipo[j].goles < equipo[j + 1].goles) {   // de mayor a menor
            Jugador temporal = equipo[j];
            equipo[j] = equipo[j + 1];
            equipo[j + 1] = temporal;
        }
    }
}
```

La comparación usa un campo (`.goles`), pero el intercambio mueve el struct completo: nombre,
número, goles y partidos siguen juntos. Con los datos del ejemplo, el orden queda Ana (12),
Sofia (9), Diego (4) y Luis (0).

## Autocheck

**¿Qué es `equipo[1]` y qué es `equipo[1].nombre`?**

`equipo[1]` es el segundo jugador completo, un `Jugador` con sus cuatro campos.
`equipo[1].nombre` es solo su nombre, un `string`.

**¿Por qué no compila `equipo.goles[i]`?**

Porque `equipo` es un arreglo y no tiene un campo `goles`. Primero se elige al jugador con el
índice y después el campo: `equipo[i].goles`.

**En el ejemplo, si Sofia y Ana tuvieran los dos 12 goles, ¿quién saldría como goleadora y
por qué?**

Sofia, porque aparece primero y la comparación es `>` (estrictamente mayor): cuando llega Ana
con los mismos goles, la condición es falsa y `goleador` no cambia.

**¿Qué ventaja tiene el arreglo de structs sobre los arreglos paralelos al ordenar?**

Que el intercambio mueve el registro completo con `=`, así que los datos de cada jugador no
se pueden separar. Con arreglos paralelos hay que intercambiar cada arreglo y basta olvidar
uno para mezclar los datos.

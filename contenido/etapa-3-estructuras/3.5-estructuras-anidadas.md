# 3.5 Estructuras anidadas

*Anterior: [3.4 Arreglos de registros](3.4-arreglos-de-registros.md)*

Un campo de un struct puede ser de cualquier tipo: `int`, `double`, `string`… y también
**otro struct**. A eso se le llama **estructura anidada**. Sirve cuando uno de los datos de
un registro está formado, a su vez, por varios datos más pequeños, como una fecha (día, mes
y año) dentro de los datos de un alumno.

## El problema: un dato que en realidad son tres

Con lo que ya sabes, guardarías la fecha de nacimiento de un alumno en tres campos sueltos:

```cpp
struct Alumno {
    string nombre;
    int diaNacimiento;
    int mesNacimiento;
    int anioNacimiento;
};
```

Funciona, pero los tres campos de la fecha no forman una unidad: no se pueden copiar de una
sola vez y, si el registro necesita **otra** fecha (por ejemplo, la de inscripción), hay que
escribir otros tres campos con otros tres nombres. Es el mismo problema que resolvió el
`struct` en [3.1](3.1-estructuras.md), ahora dentro de un registro.

## La solución: un struct dentro de otro

Se define primero el struct pequeño y después se usa como tipo de un campo del grande:

```cpp
struct Fecha {
    int dia;
    int mes;
    int anio;
};

struct Alumno {
    string nombre;
    Fecha nacimiento;   // un campo de tipo Fecha
};
```

Un `Alumno` tiene dos campos: `nombre` y `nacimiento`. Y `nacimiento`, como es un `Fecha`,
tiene adentro sus propios tres campos.

**El orden de las definiciones importa.** `Fecha` va **antes** que `Alumno`: el compilador
lee de arriba hacia abajo y, al llegar a `Fecha nacimiento;`, ya tiene que saber qué es una
`Fecha`. Si la defines después, el programa no compila.

Además, `Fecha` se puede reusar en cualquier otro struct:

```cpp
struct Prestamo {
    string libro;
    Fecha salida;
    Fecha devolucion;
};
```

## Acceso: un punto por cada nivel

Para llegar a un campo interno se encadenan los puntos, de afuera hacia adentro:

```cpp
Alumno a;
a.nombre = "Sofia";
a.nacimiento.dia = 14;
a.nacimiento.mes = 3;
a.nacimiento.anio = 2009;
```

`a.nacimiento.mes` se lee "del alumno `a`, su fecha de nacimiento, y de esa fecha, el mes".

| Expresión | ¿Es correcta? | Qué es |
|---|---|---|
| `a.nacimiento.mes` | Sí | Un `int`: el mes de nacimiento |
| `a.nacimiento` | Sí, pero es el struct completo | Una `Fecha`: sirve para copiarla, no para imprimirla con `cout` |
| `a.mes` | No compila | `Alumno` no tiene un campo `mes`; el mes está dentro de `nacimiento` |
| `cout << a.nacimiento;` | No compila | `cout` no sabe imprimir una `Fecha`; hay que imprimir campo por campo |

Como `a.nacimiento` es una `Fecha` completa, se puede copiar de una vez con `=`, igual que
cualquier struct ([3.2](3.2-definicion-de-estructuras.md)):

```cpp
Alumno gemelo;
gemelo.nombre = "Diego";
gemelo.nacimiento = a.nacimiento;   // copia dia, mes y anio juntos
```

## Inicialización con llaves dentro de llaves

Se inicializa como en [3.3](3.3-inicializacion-de-estructuras.md), en el orden de los
campos. El campo que es struct lleva **sus propias llaves**:

```cpp
Alumno a = {"Sofia", {14, 3, 2009}};
//           nombre   nacimiento: dia, mes, anio
```

En un arreglo de structs ([3.4](3.4-arreglos-de-registros.md)) se juntan los tres niveles de
llaves: el arreglo, cada alumno y su fecha.

```cpp
Alumno grupo[2] = {
    {"Sofia", {14, 3, 2009}},
    {"Diego", {2, 11, 2010}}
};
```

Y en un arreglo, el acceso empieza por el índice: `grupo[1].nacimiento.anio` es el año de
nacimiento del segundo alumno.

## Ejemplo completo: edades del grupo

El programa captura el nombre y la fecha de nacimiento de 4 alumnos, muestra una tabla con la
edad de cada uno al 15 de octubre de 2026 y dice quién es el mayor del grupo.

```cpp
#include <iostream>
#include <string>
using namespace std;

struct Fecha {
    int dia;
    int mes;
    int anio;
};

struct Alumno {
    string nombre;
    Fecha nacimiento;
};

int fechaComoNumero(int dia, int mes, int anio);
int calcularEdad(int nacimiento, int hoy);

int main() {
    const int N = 4;
    const Fecha HOY = {15, 10, 2026};
    Alumno grupo[N];

    for (int i = 0; i < N; i++) {
        cout << "Alumno " << (i + 1) << endl;
        cout << "  Nombre: ";
        cin >> grupo[i].nombre;

        do {
            cout << "  Dia de nacimiento (1 a 31): ";
            cin >> grupo[i].nacimiento.dia;
            if (grupo[i].nacimiento.dia < 1 || grupo[i].nacimiento.dia > 31) {
                cout << "  ERROR! Dia no valido." << endl;
            }
        } while (grupo[i].nacimiento.dia < 1 || grupo[i].nacimiento.dia > 31);

        do {
            cout << "  Mes de nacimiento (1 a 12): ";
            cin >> grupo[i].nacimiento.mes;
            if (grupo[i].nacimiento.mes < 1 || grupo[i].nacimiento.mes > 12) {
                cout << "  ERROR! Mes no valido." << endl;
            }
        } while (grupo[i].nacimiento.mes < 1 || grupo[i].nacimiento.mes > 12);

        do {
            cout << "  Anio de nacimiento: ";
            cin >> grupo[i].nacimiento.anio;
            if (grupo[i].nacimiento.anio > HOY.anio) {
                cout << "  ERROR! No puede ser despues de " << HOY.anio << "." << endl;
            }
        } while (grupo[i].nacimiento.anio > HOY.anio);
    }

    int hoy = fechaComoNumero(HOY.dia, HOY.mes, HOY.anio);
    int mayor = 0;   // posicion del alumno de mayor edad

    cout << endl << "Nombre\tNacimiento\tEdad" << endl;
    for (int i = 0; i < N; i++) {
        int nacimiento = fechaComoNumero(grupo[i].nacimiento.dia,
                                         grupo[i].nacimiento.mes,
                                         grupo[i].nacimiento.anio);

        cout << grupo[i].nombre << "\t"
             << grupo[i].nacimiento.dia << "/" << grupo[i].nacimiento.mes << "/"
             << grupo[i].nacimiento.anio << "\t"
             << calcularEdad(nacimiento, hoy) << endl;

        if (nacimiento < fechaComoNumero(grupo[mayor].nacimiento.dia,
                                         grupo[mayor].nacimiento.mes,
                                         grupo[mayor].nacimiento.anio)) {
            mayor = i;
        }
    }

    cout << endl << "Mayor del grupo: " << grupo[mayor].nombre
         << " (nacimiento: " << grupo[mayor].nacimiento.dia << "/"
         << grupo[mayor].nacimiento.mes << "/" << grupo[mayor].nacimiento.anio << ")" << endl;

    return 0;
}

int fechaComoNumero(int dia, int mes, int anio) {
    return anio * 10000 + mes * 100 + dia;
}

int calcularEdad(int nacimiento, int hoy) {
    return (hoy - nacimiento) / 10000;
}
```

Con `Sofia 14 3 2009`, `Diego 2 11 2010`, `Ana 30 10 2009` y `Luis 15 10 2010`:

```
Nombre	Nacimiento	Edad
Sofia	14/3/2009	17
Diego	2/11/2010	15
Ana	30/10/2009	16
Luis	15/10/2010	16

Mayor del grupo: Sofia (nacimiento: 14/3/2009)
```

Detalles del programa:

- **`HOY` también es una `Fecha`**, inicializada con llaves. El mismo tipo sirve para la
  fecha de nacimiento de cada alumno y para la fecha de corte.
- **`fechaComoNumero` convierte una fecha en un número de la forma `aaaammdd`**: 14/3/2009
  queda como `20090314`. Escrita así, una fecha anterior siempre da un número menor, de modo
  que comparar fechas se vuelve comparar dos `int` con `<`. Así se busca al mayor del grupo:
  el que nació **antes**, es decir, el de número más chico. Es la misma búsqueda del menor
  de [2.4](../etapa-2-arreglos/2.4-recorrido-con-for.md), guardando la posición.
- **`calcularEdad` resta los dos números y se queda con los años completos.** Para Sofia:
  `20261015 - 20090314 = 170701`, y `170701 / 10000 = 17` (división entera). Las cifras de
  mes y día de la resta hacen que, si el cumpleaños todavía no llega, se reste un año: Ana
  nació en 2009, pero cumple el 30 de octubre, así que el 15 de octubre todavía tiene 16.
- **Las dos funciones son puras y reciben campos sueltos** (`int`), como en
  [3.3](3.3-inicializacion-de-estructuras.md): no reciben el struct.
- **La validación del día es sencilla:** acepta del 1 al 31 en cualquier mes, así que no
  detecta un 31 de abril o un 30 de febrero.

## Cuando no sabes cuántos registros habrá: el contador

Hasta ahora el arreglo se llena completo: `N` alumnos, ni uno más ni uno menos. En un
programa real los registros llegan de uno en uno y no se sabe cuántos serán. La solución es
declarar el arreglo con una **capacidad** máxima y llevar un contador `n` de cuántos
registros hay ocupados:

- Si hay `n` registros, ocupan las posiciones `0` a `n - 1`, y el **siguiente se guarda en la
  posición `n`**. Después de guardarlo, `n` aumenta en 1.
- Antes de agregar, se revisa que `n` sea menor que la capacidad. Si no, el arreglo está
  lleno: guardar en `grupo[n]` escribiría fuera del arreglo
  ([2.2](../etapa-2-arreglos/2.2-creacion-de-arrays.md)).
- Para recorrer, el `for` llega hasta `n`, **no** hasta la capacidad: las posiciones
  siguientes nunca se llenaron y tienen basura.

```cpp
#include <iostream>
#include <string>
using namespace std;

struct Fecha {
    int dia;
    int mes;
    int anio;
};

struct Alumno {
    string nombre;
    Fecha nacimiento;
};

int main() {
    const int CAPACIDAD = 3;
    Alumno grupo[CAPACIDAD];
    int n = 0;          // cuantos alumnos hay registrados
    int opcion;

    do {
        cout << endl << "1. Agregar alumno  2. Ver alumnos  3. Salir" << endl;
        cout << "Opcion: ";
        cin >> opcion;

        if (opcion == 1) {
            if (n < CAPACIDAD) {
                cout << "  Nombre: ";
                cin >> grupo[n].nombre;
                cout << "  Nacimiento (dia mes anio): ";
                cin >> grupo[n].nacimiento.dia >> grupo[n].nacimiento.mes
                    >> grupo[n].nacimiento.anio;
                n++;
            } else {
                cout << "  ERROR! Ya no hay espacio para mas alumnos." << endl;
            }
        } else if (opcion == 2) {
            cout << "  Alumnos registrados: " << n << endl;
            for (int i = 0; i < n; i++) {
                cout << "  " << (i + 1) << ". " << grupo[i].nombre << " - "
                     << grupo[i].nacimiento.dia << "/" << grupo[i].nacimiento.mes
                     << "/" << grupo[i].nacimiento.anio << endl;
            }
        }
    } while (opcion != 3);

    return 0;
}
```

La capacidad es 3 para que sea fácil llegar al límite. Agregando a Sofia, Diego y Ana, un
cuarto intento de agregar muestra el error, y la opción 2 lista solo a los tres registrados:

```
Opcion: 1
  ERROR! Ya no hay espacio para mas alumnos.

1. Agregar alumno  2. Ver alumnos  3. Salir
Opcion: 2
  Alumnos registrados: 3
  1. Sofia - 14/3/2009
  2. Diego - 2/11/2010
  3. Ana - 30/10/2009
```

Al elegir 3 el programa termina y **los datos se pierden**: viven en memoria solo mientras el
programa corre. Guardarlos para la siguiente vez es justo el tema de la Etapa IV, archivos.

## Autocheck

**Si `grupo` es un arreglo de `Alumno`, ¿qué tipo de dato es cada una de estas expresiones:
`grupo[2]`, `grupo[2].nacimiento` y `grupo[2].nacimiento.mes`?**

`grupo[2]` es un `Alumno` completo; `grupo[2].nacimiento` es una `Fecha` completa;
`grupo[2].nacimiento.mes` es un `int`.

**¿Por qué no compila el programa si `struct Fecha` se escribe después de `struct Alumno`?**

Porque el compilador lee de arriba hacia abajo y, al llegar al campo `Fecha nacimiento;`,
todavía no sabe qué es una `Fecha`.

**Escribe la inicialización con llaves de un alumno llamado Luis que nació el 15 de octubre
de 2010.**

`Alumno luis = {"Luis", {15, 10, 2010}};`

**En el ejemplo, Ana nació en 2009 igual que Sofia. ¿Por qué Ana tiene 16 años y Sofia 17?**

Porque al 15 de octubre de 2026 Sofia ya cumplió años (el 14 de marzo) y Ana todavía no (los
cumple el 30 de octubre). En la resta, `20261015 - 20091030 = 169985`, y la división entera
entre 10000 da 16.

**En el programa del contador hay 2 alumnos registrados. ¿En qué posición se guarda el
siguiente y hasta qué valor de `i` llega el `for` que los lista?**

El siguiente se guarda en la posición 2 (`grupo[n]` con `n = 2`). El `for` llega hasta
`i = 1`, porque la condición es `i < n`: recorre solo las posiciones ocupadas, 0 y 1.

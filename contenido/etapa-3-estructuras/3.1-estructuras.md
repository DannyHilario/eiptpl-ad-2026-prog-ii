# 3.1 Estructuras

*Anterior: [2.8 Ordenamiento burbuja](../etapa-2-arreglos/2.8-ordenamiento-burbuja.md) — Siguiente: [3.2 Definición de estructuras](3.2-definicion-de-estructuras.md)*

En la Etapa II aprendiste a guardar **muchos datos del mismo tipo** en un arreglo: las 7
temperaturas de una semana, las calificaciones de un grupo. Pero muchos datos del mundo
real no son "muchos de lo mismo", sino **varias cosas distintas que describen a una sola
cosa**. Un jugador de un torneo tiene un nombre (texto), un número de playera (entero),
goles anotados (entero) y partidos jugados (entero). Son cuatro datos, de tipos distintos,
que solo tienen sentido **juntos**.

## El problema: datos sueltos que deberían ir juntos

Con lo que sabes hasta ahora, guardarías al jugador en cuatro variables sueltas:

```cpp
string nombre;
int numero;
int goles;
int partidos;
```

Funciona para un jugador, pero nada en el programa dice que esas cuatro variables
pertenecen a la misma persona. Si necesitas un segundo jugador, terminas con `nombre2`,
`numero2`, `goles2`, `partidos2`... y con el riesgo de mezclar el nombre de uno con los
goles de otro.

## La solución: un `struct`

Una **estructura** (`struct`) es un **tipo de dato nuevo, definido por ti**, que agrupa
varias variables relacionadas bajo un solo nombre. A cada variable de adentro se le llama
**miembro** o **campo**.

```cpp
struct Jugador {
    string nombre;
    int numero;
    int goles;
    int partidos;
};
```

Con esto, `Jugador` se vuelve un tipo de dato igual que `int` o `double`, y puedes
declarar variables de ese tipo:

```cpp
Jugador capitan;
```

`capitan` es **una sola variable** que lleva adentro los cuatro datos del jugador.

## Acceso a los campos: el operador punto

Para leer o modificar un campo se escribe el nombre de la variable, un **punto** y el
nombre del campo:

```cpp
capitan.goles = 7;                   // modificar un campo
cout << capitan.goles << endl;       // leerlo
cin >> capitan.nombre;               // capturarlo
```

Cada `capitan.campo` se comporta exactamente como una variable normal de su tipo:
`capitan.goles` es un `int`, así que puedes sumarle, compararlo o usarlo en una división
como cualquier otro `int`.

## Ejemplo completo

```cpp
#include <iostream>
#include <string>
using namespace std;

struct Jugador {
    string nombre;
    int numero;
    int goles;
    int partidos;
};

int main() {
    Jugador capitan;

    cout << "Nombre: ";
    cin >> capitan.nombre;
    cout << "Numero de playera: ";
    cin >> capitan.numero;
    cout << "Goles anotados: ";
    cin >> capitan.goles;
    cout << "Partidos jugados: ";
    cin >> capitan.partidos;

    double promedio = (double) capitan.goles / capitan.partidos;

    cout << endl;
    cout << "Jugador: " << capitan.nombre << " (#" << capitan.numero << ")" << endl;
    cout << "Goles por partido: " << promedio << endl;

    return 0;
}
```

Con la entrada `Sofia 10 9 6`, después de las preguntas imprime:

```
Jugador: Sofia (#10)
Goles por partido: 1.5
```

El `(double)` es el mismo que ya usaste para promediar: `goles` y `partidos` son `int`, y
sin la conversión la división sería entera (9 / 6 daría 1).

## ¿Struct o arreglo?

Las dos herramientas agrupan datos, pero responden a preguntas distintas:

| | Arreglo | Struct |
|---|---|---|
| ¿Qué agrupa? | Muchos datos **del mismo tipo** | Datos **de tipos distintos** que describen una sola cosa |
| ¿Cómo se accede? | Por posición: `goles[3]` | Por nombre: `capitan.goles` |
| Ejemplo | Las 7 temperaturas de una semana | Nombre, número y goles de un jugador |

Y se pueden combinar: un **arreglo de structs** guarda a todos los jugadores de un equipo,
cada uno con sus cuatro datos. Eso lo verás en
[3.4 Arreglos de registros](3.4-arreglos-de-registros.md).

> El manual también llama **registro** a una estructura, y **campos** a sus miembros. Son
> sinónimos: verás las tres palabras.

## Autocheck

**¿Qué diferencia hay entre un arreglo y un `struct`?**

Un arreglo guarda muchos datos del mismo tipo y se accede a cada uno por su posición
(`goles[3]`). Un `struct` agrupa datos que pueden ser de tipos distintos y que describen
una sola cosa, y se accede a cada uno por su nombre (`capitan.goles`).

**Si `capitan` es una variable de tipo `Jugador`, ¿de qué tipo es `capitan.nombre`?**

`string`, porque así se declaró ese campo dentro del `struct`. Cada campo conserva su
propio tipo.

**En el ejemplo, ¿qué imprimiría el promedio si quitas el `(double)` y capturas 9 goles en 6
partidos?**

`1`, porque `capitan.goles / capitan.partidos` sería una división entre dos `int` y C++
descarta los decimales.

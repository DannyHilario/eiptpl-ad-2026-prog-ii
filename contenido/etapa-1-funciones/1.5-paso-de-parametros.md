# 1.5 Paso de parámetros

*Anterior: [1.4 Reglas de alcance](1.4-reglas-de-alcance.md) — Siguiente: [2.1 Arreglos](../etapa-2-arreglos/2.1-arreglos.md)*

Un **parámetro** es la forma en que una función recibe información de quien la llama. Hasta
ahora todas tus funciones recibían números sueltos (`int`, `double`) y regresaban un resultado
con `return`. Esta sesión explica qué pasa exactamente con esos datos al llamar a la función y
cómo se pasan los tipos compuestos: **arreglos** y **estructuras**.

> Esta sesión se escribió como apoyo para el PIA, al final del curso: para separar un programa
> en una función por cada opción del menú, esas funciones necesitan recibir el arreglo de
> structs. Por eso requiere haber visto las Etapas II (arreglos) y III (estructuras, hasta
> 3.5). Lo que se usó en el PIA está en [1.5.3](#153-paso-de-parámetros-de-tipos-compuestos).

## 1.5.1 Paso por valor: la función recibe una copia

Es la forma que has usado siempre. Al llamar a la función, el valor se **copia** al parámetro;
la función trabaja con su copia y la variable original no cambia.

```cpp
#include <iostream>
using namespace std;

void duplicar(int numero) {
    numero = numero * 2;
    cout << "Dentro de duplicar: " << numero << endl;
}

int main() {
    int puntos = 10;
    duplicar(puntos);
    cout << "En main: " << puntos << endl;
    return 0;
}
```

Salida:

```
Dentro de duplicar: 20
En main: 10
```

`numero` y `puntos` son **dos variables distintas**: al llamar `duplicar(puntos)`, el 10 se
copió a `numero`. Duplicar `numero` no toca a `puntos`. Por eso, cuando una función calcula
algo, lo **regresa** con `return` y quien la llama lo guarda:
`puntos = calcularDoble(puntos);`.

## 1.5.2 Paso por referencia: la función trabaja con la original

Si se escribe `&` después del tipo del parámetro, la función ya no recibe una copia: el
parámetro se vuelve **otro nombre** (un alias) de la variable original.

```cpp
#include <iostream>
using namespace std;

void duplicar(int &numero) {
    numero = numero * 2;
}

int main() {
    int puntos = 10;
    duplicar(puntos);
    cout << "En main: " << puntos << endl;
    return 0;
}
```

Salida:

```
En main: 20
```

El único cambio es el `&` en `int &numero`, y ahora `puntos` sí cambió.

En este curso **casi no lo usaremos**: una función que regresa su resultado con `return` deja
claro qué entra y qué sale, y no modifica variables "a escondidas". Conviene conocerlo porque
lo vas a ver en código de otros, y porque explica lo que pasa con los arreglos.

## 1.5.3 Paso de parámetros de tipos compuestos

### 1.5.3.1 Arreglos como parámetros

Un arreglo se pasa escribiendo su nombre **sin corchetes** en la llamada, y en la función el
parámetro se declara con **corchetes vacíos**:

```cpp
#include <iostream>
using namespace std;

const int SEMANAS = 4;

double calcularPromedio(double datos[], int cantidad);
void reiniciar(double datos[], int cantidad);

int main() {
    double alturas[SEMANAS] = {12.5, 14, 15.5, 18};

    cout << "Promedio: " << calcularPromedio(alturas, SEMANAS) << endl;

    reiniciar(alturas, SEMANAS);
    cout << "Despues de reiniciar: " << alturas[0] << " " << alturas[3] << endl;
    return 0;
}

double calcularPromedio(double datos[], int cantidad) {
    double suma = 0;
    for (int i = 0; i < cantidad; i++) {
        suma += datos[i];
    }
    return suma / cantidad;
}

void reiniciar(double datos[], int cantidad) {
    for (int i = 0; i < cantidad; i++) {
        datos[i] = 0;
    }
}
```

Salida:

```
Promedio: 15
Despues de reiniciar: 0 0
```

Tres cosas que hay que notar:

**1. El arreglo NO se copia.** A diferencia de un `int`, la función recibe el arreglo
**original** (técnicamente, dónde empieza en la memoria). Por eso `reiniciar` sí cambió los
datos de `alturas` en `main`, aunque no lleva `&`. Esto es útil: una función puede **llenar** o
**modificar** un arreglo, y los cambios se quedan.

**2. El tamaño no viaja con el arreglo.** Dentro de la función, `datos[]` no sabe cuántas
casillas tiene. Por eso siempre se manda **otro parámetro** con cuántos datos recorrer
(`cantidad`). Si el arreglo está lleno solo en parte (como un arreglo de registros con su
contador), se manda **cuántos hay ocupados**, no la capacidad.

**3. En la llamada va solo el nombre:** `calcularPromedio(alturas, SEMANAS)`. Escribir
`alturas[]` o `alturas[SEMANAS]` en la llamada es un error.

### 1.5.3.2 Estructuras como parámetros

Un `struct` se comporta como un `int`: **por valor se copia** y **por referencia (`&`) se
modifica el original**.

```cpp
#include <iostream>
#include <string>
using namespace std;

struct Fecha {
    int dia;
    int mes;
    int anio;
};

void mostrarFecha(Fecha f);
void adelantarAnio(Fecha f);
void adelantarAnioReferencia(Fecha &f);

int main() {
    Fecha siembra = {15, 3, 2026};

    mostrarFecha(siembra);
    adelantarAnio(siembra);
    mostrarFecha(siembra);
    adelantarAnioReferencia(siembra);
    mostrarFecha(siembra);
    return 0;
}

void mostrarFecha(Fecha f) {
    cout << f.dia << "/" << f.mes << "/" << f.anio << endl;
}

void adelantarAnio(Fecha f) {
    f.anio++;                // cambia la copia
}

void adelantarAnioReferencia(Fecha &f) {
    f.anio++;                // cambia la original
}
```

Salida:

```
15/3/2026
15/3/2026
15/3/2027
```

`adelantarAnio` cambió su copia y la fecha de `main` siguió igual; `adelantarAnioReferencia`,
con `&`, sí la cambió.

### Un arreglo de structs como parámetro

Un arreglo de structs es **un arreglo**, así que sigue la regla de 1.5.3.1: se pasa sin
corchetes, **no se copia** y la función puede modificar sus registros. Junto con el arreglo se
manda el contador `n`, para que la función recorra solo los registros ocupados (como en
[3.5](../etapa-3-estructuras/3.5-estructuras-anidadas.md)).

Este vivero guarda hasta 5 plantas, con la altura de cada una en 3 semanas. Cada opción del
menú vive en su propia función, y `main` solo tiene el menú:

```cpp
#include <iostream>
#include <string>
using namespace std;

const int MAX_PLANTAS = 5;
const int SEMANAS = 3;

struct Planta {
    string clave;
    double alturas[SEMANAS];
    double promedioAltura;
};

// Funciones que hablan con el usuario: una por opcion del menu
int registrarPlanta(Planta plantas[], int n);
void mostrarPlantas(Planta plantas[], int n);
void consultarPlanta(Planta plantas[], int n);

// Funciones sin cin ni cout: solo buscan o calculan
int buscarPosicion(Planta plantas[], int n, string clave);
double calcularPromedio(double datos[], int cantidad);

int main() {
    Planta plantas[MAX_PLANTAS];
    int n = 0;
    int opcion;

    do {
        cout << endl << "VIVERO" << endl;
        cout << "1. Registrar  2. Mostrar  3. Consultar  4. Salir" << endl;
        cout << "Opcion: ";
        cin >> opcion;

        switch (opcion) {
            case 1:
                n = registrarPlanta(plantas, n);   // la funcion regresa el nuevo n
                break;
            case 2:
                mostrarPlantas(plantas, n);
                break;
            case 3:
                consultarPlanta(plantas, n);
                break;
            case 4:
                break;
            default:
                cout << "ERROR! Opcion no valida" << endl;
        }
    } while (opcion != 4);

    return 0;
}

int registrarPlanta(Planta plantas[], int n) {
    if (n == MAX_PLANTAS) {
        cout << "El vivero esta lleno" << endl;
        return n;                       // no cambia: no se registro nada
    }

    string clave;
    cout << "Clave: ";
    cin >> clave;
    if (buscarPosicion(plantas, n, clave) != -1) {
        cout << "ERROR! Esa clave ya existe" << endl;
        return n;
    }

    plantas[n].clave = clave;
    for (int s = 0; s < SEMANAS; s++) {
        cout << "Altura semana " << s + 1 << " (cm): ";
        cin >> plantas[n].alturas[s];
    }
    plantas[n].promedioAltura = calcularPromedio(plantas[n].alturas, SEMANAS);
    cout << "Promedio: " << plantas[n].promedioAltura << " cm" << endl;

    return n + 1;                       // ahora hay una planta mas
}

void mostrarPlantas(Planta plantas[], int n) {
    if (n == 0) {
        cout << "No hay plantas registradas" << endl;
        return;
    }
    for (int i = 0; i < n; i++) {
        cout << plantas[i].clave << "\t" << plantas[i].promedioAltura << " cm" << endl;
    }
}

void consultarPlanta(Planta plantas[], int n) {
    string clave;
    cout << "Clave a buscar: ";
    cin >> clave;

    int posicion = buscarPosicion(plantas, n, clave);
    if (posicion == -1) {
        cout << "No se encontro " << clave << endl;
    } else {
        cout << "Alturas:";
        for (int s = 0; s < SEMANAS; s++) {
            cout << " " << plantas[posicion].alturas[s];
        }
        cout << endl << "Promedio: " << plantas[posicion].promedioAltura << " cm" << endl;
    }
}

int buscarPosicion(Planta plantas[], int n, string clave) {
    for (int i = 0; i < n; i++) {
        if (plantas[i].clave == clave) {
            return i;
        }
    }
    return -1;
}

double calcularPromedio(double datos[], int cantidad) {
    double suma = 0;
    for (int i = 0; i < cantidad; i++) {
        suma += datos[i];
    }
    return suma / cantidad;
}
```

Una ejecución:

```
VIVERO
1. Registrar  2. Mostrar  3. Consultar  4. Salir
Opcion: 1
Clave: R01
Altura semana 1 (cm): 12.5
Altura semana 2 (cm): 14
Altura semana 3 (cm): 15.5
Promedio: 14 cm

VIVERO
1. Registrar  2. Mostrar  3. Consultar  4. Salir
Opcion: 1
Clave: R02
Altura semana 1 (cm): 20
Altura semana 2 (cm): 22
Altura semana 3 (cm): 27
Promedio: 23 cm

VIVERO
1. Registrar  2. Mostrar  3. Consultar  4. Salir
Opcion: 1
Clave: R01
ERROR! Esa clave ya existe

VIVERO
1. Registrar  2. Mostrar  3. Consultar  4. Salir
Opcion: 2
R01	14 cm
R02	23 cm

VIVERO
1. Registrar  2. Mostrar  3. Consultar  4. Salir
Opcion: 3
Clave a buscar: R02
Alturas: 20 22 27
Promedio: 23 cm
```

Lo importante, función por función:

| Función | Qué recibe | Qué hace con el arreglo | Qué regresa |
|---|---|---|---|
| `registrarPlanta` | El arreglo y cuántas plantas hay | **Escribe** en `plantas[n]` | El **nuevo** número de plantas |
| `mostrarPlantas` | El arreglo y cuántas hay | Solo lee, de `0` a `n - 1` | Nada (`void`) |
| `consultarPlanta` | El arreglo y cuántas hay | Solo lee la planta encontrada | Nada (`void`) |
| `buscarPosicion` | El arreglo, cuántas hay y la clave | Solo lee | La posición, o `-1` si no está |
| `calcularPromedio` | **Un arreglo de `double`** y cuántos datos | Solo lee | El promedio |

**¿Por qué `registrarPlanta` regresa `n`?** La función escribe la planta nueva en el arreglo, y
eso sí se queda en `main` porque los arreglos no se copian. Pero `n` es un `int`: se pasa **por
valor**, así que si la función hiciera `n++`, solo cambiaría su copia. Por eso regresa el nuevo
valor y `main` lo guarda: `n = registrarPlanta(plantas, n);`. Si no registró nada (vivero lleno
o clave repetida), regresa el mismo `n`. Se podría resolver con `int &n`, pero regresar el valor
deja más claro, en `main`, que el contador puede cambiar en esa línea.

**Un campo que es arreglo también se puede mandar:**
`calcularPromedio(plantas[n].alturas, SEMANAS)` le pasa a la función el arreglo `alturas` de
**una** planta. `calcularPromedio` no sabe nada de plantas: recibe un arreglo de `double`, igual
que en el ejemplo de 1.5.3.1. Por eso la misma función serviría para cualquier arreglo de datos.

**`buscarPosicion` se usa en dos lugares:** en `registrarPlanta`, para no repetir una clave, y
en `consultarPlanta`, para encontrar la planta. Es la búsqueda lineal de
[2.6](../etapa-2-arreglos/2.6-busqueda-lineal.md), ahora en una función que recibe el arreglo.

**`return;` en una función `void`** termina la función ahí, sin regresar nada: `mostrarPlantas`
avisa que no hay plantas y se sale sin llegar al `for`.

### Dos tipos de funciones

Cuando cada opción del menú vive en su función, el programa tiene dos tipos:

| | Funciones de opción | Funciones de cálculo o búsqueda |
|---|---|---|
| Ejemplos | `registrarPlanta`, `mostrarPlantas`, `consultarPlanta` | `buscarPosicion`, `calcularPromedio` |
| ¿Usan `cin` y `cout`? | Sí: son las que hablan con el usuario | **No** |
| ¿Quién las llama? | `main`, desde el menú | Otras funciones |

Las de cálculo son las funciones puras de
[1.3](1.3-funciones-definidas-por-el-usuario.md#debe-una-función-hacer-cincout-ella-misma-o-solo-calcular):
como no imprimen nada, sirven en cualquier parte del programa.

## Autocheck

**En el ejemplo de 1.5.1, ¿por qué `puntos` sigue valiendo 10 después de llamar a
`duplicar(puntos)`?**

Porque se pasó por valor: `numero` recibió una copia del 10. Duplicar la copia no cambia la
variable original.

**¿Qué cambia si el parámetro se declara `int &numero`?**

`numero` se vuelve otro nombre de la variable original, así que lo que la función le haga a
`numero` también le pasa a `puntos`.

**Una función recibe `double datos[]` y le asigna 0 a cada casilla. ¿Los datos del arreglo de
`main` cambian? ¿Por qué no hizo falta `&`?**

Sí cambian. Los arreglos no se copian: la función trabaja con el arreglo original.

**¿Por qué una función que recibe un arreglo casi siempre recibe también un `int` con la
cantidad?**

Porque el tamaño no viaja con el arreglo: la función no tiene forma de saber cuántas casillas
recorrer si no se le dice.

**En el vivero, ¿qué pasaría si `registrarPlanta` hiciera `n++` y no regresara nada, y `main`
la llamara como `registrarPlanta(plantas, n);`?**

La planta sí quedaría escrita en el arreglo, pero `n` de `main` seguiría igual, porque el `n` de
la función es una copia. La siguiente planta se escribiría encima de la anterior y la opción 2
nunca la mostraría.

**¿Por qué `buscarPosicion` no imprime "No se encontró"?**

Porque es una función de búsqueda: solo regresa la posición o `-1`. Quien la llama decide qué
hacer con eso: `registrarPlanta` la usa para rechazar una clave repetida y `consultarPlanta`
para avisar que no la encontró.

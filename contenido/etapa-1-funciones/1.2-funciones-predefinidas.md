# 1.2 Funciones predefinidas

*Anterior: [1.1 Funciones](1.1-funciones.md) — Siguiente: [1.3 Funciones definidas por el usuario](1.3-funciones-definidas-por-el-usuario.md)*

## ¿Qué es una función predefinida?

C++ trae, además del lenguaje en sí, un conjunto de **bibliotecas** con funciones ya
escritas y listas para usar — no tienes que programarlas tú. A esto se le llama
**biblioteca estándar**. Ya usaste dos de sus piezas más importantes: `cout` y `cin`
vienen de la biblioteca `<iostream>`.

Para usar una función predefinida necesitas dos cosas:

1. Hacer `#include` de la biblioteca donde vive (el header le dice al compilador que
   la función existe y qué tipo de datos recibe y regresa).
2. Llamarla como llamarías a cualquier función: `nombre(argumentos)`.

No necesitas saber cómo está escrito el código interno de `sqrt` o `isdigit` — solo
qué recibe, qué regresa, y de qué biblioteca viene. Es exactamente el mismo trato que
le das a `cout`: la usas sin haber visto ni una línea de su implementación.

## `<cmath>` — funciones matemáticas

La biblioteca `<cmath>` trae funciones matemáticas comunes. Las más usadas en este
curso:

| Función | Qué hace | Ejemplo |
|---|---|---|
| `sqrt(x)` | Raíz cuadrada de `x` | `sqrt(16)` → `4` |
| `pow(base, exponente)` | `base` elevado a `exponente` | `pow(2, 3)` → `8` |
| `fabs(x)` | Valor absoluto de un `double` | `fabs(-5.5)` → `5.5` |

**Ejemplo 1**

```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    double numero;
    cout << "Escribe un numero: ";
    cin >> numero;

    cout << "Raiz cuadrada: " << sqrt(numero) << endl;
    cout << "Valor absoluto: " << fabs(numero) << endl;
    cout << "Elevado al cuadrado: " << pow(numero, 2) << endl;

    return 0;
}
```

Con `16` como entrada, imprime `4`, `16` y `256`.

## `<cctype>` — clasificar y convertir caracteres

La biblioteca `<cctype>` trae funciones para revisar o transformar un solo carácter
(`char`):

| Función | Qué hace |
|---|---|
| `isdigit(c)` | ¿`c` es un dígito ('0'-'9')? |
| `isalpha(c)` | ¿`c` es una letra? |
| `isupper(c)` / `islower(c)` | ¿`c` está en mayúscula / minúscula? |
| `toupper(c)` / `tolower(c)` | Regresa `c` convertido a mayúscula / minúscula |

**Ejemplo 2**

```cpp
#include <iostream>
#include <cctype>
using namespace std;

int main() {
    char letra;
    cout << "Escribe un solo caracter: ";
    cin >> letra;

    if (isdigit(letra)) {
        cout << letra << " es un digito.\n";
    } else if (isalpha(letra)) {
        cout << letra << " es una letra.\n";
        if (isupper(letra)) {
            cout << "Esta en mayuscula. En minuscula es: " << (char) tolower(letra) << endl;
        } else {
            cout << "Esta en minuscula. En mayuscula es: " << (char) toupper(letra) << endl;
        }
    } else {
        cout << letra << " no es ni letra ni digito.\n";
    }

    return 0;
}
```

Nota el `(char)` antes de `tolower(letra)`/`toupper(letra)`: estas funciones en
realidad regresan un `int` (por razones históricas del lenguaje C, del que C++
heredó `<cctype>`), así que hay que convertirlo de vuelta a `char` para que `cout`
lo imprima como letra y no como número.

## `<cstdlib>` — utilidades generales

La biblioteca `<cstdlib>` trae, entre otras cosas, funciones para convertir texto a
número y calcular valores absolutos de enteros:

| Función | Qué hace |
|---|---|
| `atoi(texto)` | Convierte un `const char*` (texto) a `int` |
| `abs(n)` | Valor absoluto de un `int` (para `double` se usa `fabs`, de `<cmath>`) |

**Ejemplo 3**

```cpp
#include <iostream>
#include <string>
#include <cstdlib>
using namespace std;

int main() {
    string texto;
    cout << "Escribe un numero (como texto): ";
    cin >> texto;

    int numero = atoi(texto.c_str());
    cout << "Convertido a entero: " << numero << endl;
    cout << "Valor absoluto: " << abs(numero) << endl;

    return 0;
}
```

`texto.c_str()` convierte un `string` de C++ al formato de texto que `atoi` espera
(herencia de C, igual que `<cctype>`) — por ahora basta con saber que ese es el
"pegamento" necesario entre un `string` y funciones como `atoi`.

## Autocheck

**¿Por qué `sqrt(16)` funciona si tú nunca escribiste el código de `sqrt`?**

Porque es una función predefinida de la biblioteca `<cmath>`: ya viene compilada
dentro de la biblioteca estándar de C++. El `#include <cmath>` solo trae la
declaración (qué recibe, qué regresa), no la implementación — igual que pasa con
`cout` e `<iostream>`.

**¿Qué pasaría si intentas usar `sqrt` sin poner `#include <cmath>`?**

Un error de compilación (`sqrt` no declarado / "was not declared in this scope"),
porque el compilador no tiene forma de saber que esa función existe si no se le
avisa con el `#include` correspondiente.

**¿Por qué `toupper(letra)` hay que convertirlo con `(char)` antes de imprimirlo?**

Porque `toupper` regresa un `int`, no un `char` — una particularidad heredada de C.
Sin la conversión, `cout` podría imprimir el código numérico del carácter en vez del
carácter mismo, según el contexto en el que se use.

# Carpeta `datos/`

Aquí el programa guarda `historico-temperaturas.txt`. La carpeta tiene que existir
antes de correrlo: `ofstream` puede crear el archivo, pero no la carpeta. Este
`README.md` está aquí solo para que git conserve la carpeta (git no guarda carpetas
vacías).

El `.txt` no se sube al repo: lo crea el programa la primera vez que se ejecuta.
